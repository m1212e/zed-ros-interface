# ROS Interface for Zed

Syntax highlighting for ROS 2 interface files (`.msg`, `.srv`, `.action`) in Zed.

Uses the [tree-sitter-ros-interface](https://github.com/SuperJappie08/tree-sitter-ros-interface) grammar by Jasper van Brakel. The highlight queries are adapted from there.

## Install

Search for "ROS Interface" in Zed's extensions panel.

To try a local copy, clone this repo and run `zed: install dev extension` from the command palette.
